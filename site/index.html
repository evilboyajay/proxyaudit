Start testing in three steps

  1. Install

    Download the DMG and drag ProxyAudit to Applications.

  2. Open a browser

    Click Open browser. It's already set up to use the proxy and trust its certificate.

  3. Browse your target

    Traffic appears in Proxy. Send anything to Repeater, Intruder or the agent.

The app isn't notarized yet. On first launch, open System Settings → Privacy & Security and click Open Anyway.

Questions

Is ProxyAudit really a free alternative to Burp Suite?

Yes. It's MIT-licensed and covers the manual testing workflow: Proxy, Repeater, Intruder, Sequencer, Decoder, Comparer, Collaborator and extensions. It doesn't have an active scanner yet.

Is Intruder rate-limited like in Burp Community Edition?

No. Intruder runs as fast as your target and network allow.

Do I need an Anthropic API key?

No. If you've signed in to Claude Code with claude login, ProxyAudit uses that session. An ANTHROPIC_API_KEY also works. Everything except the AI features works without either.

Does it run on Windows or Linux?

Not yet. It runs on macOS 13 or later. Windows and Linux builds are on the roadmap, and contributions are welcome.

Can I test any website with it?

Only systems you own or have written permission to test. Intercepting other people's traffic may be illegal where you live.
